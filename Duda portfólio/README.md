# Portfólio — Maria Eduarda Paes

Site estático responsivo, criado em HTML, CSS e JavaScript.

## Como visualizar

Abra `index.html` diretamente ou rode um servidor local:

```powershell
npx serve .
```

## Personalização rápida

- Substitua `assets/maria-hero.png` pelo banner final mantendo o mesmo nome.
- Atualize e-mail e redes na seção `#contato` do `index.html`.
- Os cases usam imagens e links publicados pela Mireva.
